# Placeholder audio: attribution and licence record

Every file in this folder comes from a source whose licence was checked on that item's own page on **2026-10-07 (around 3:45 to 3:50 PM ET)**. A saved copy of each page is in `art-sources/audio/placeholder/_sources/page_snapshots/`. Everything here is **CC0 1.0 (public domain dedication)**. CC0 doesn't require credit, but the authors are credited here anyway.

- No AI-generated audio was used, and no source was put through an AI tool. The only edits were trimming, fades, a high-pass filter, a loop crossfade, resampling, channel changes and peak normalisation, all done with ffmpeg and numpy. `art-sources/audio/placeholder/_tools/build.py` rebuilds every file exactly from `art-sources/audio/placeholder/_sources/`.
- All outputs are 48 kHz, 16-bit PCM WAV, peak-normalised to -1.0 dBFS (sample peak).
- **Freesound files are the public HQ previews, not the originals.** Freesound only gives out the original files after login, so the CDN `-hq.ogg` previews were used instead (Ogg Vorbis, about 192 kbps, lossy). The licence is the same for the preview and the original. Before release, swap in the lossless originals from a logged-in Freesound account and re-run `art-sources/audio/placeholder/_tools/build.py`.
- Kenney packs have no page per file. The licence is stated on the pack page and in `License.txt` inside the zip (both were checked).

## Licence notes and doubts (none of them blocking)
- **combat_loop (banan_ 385895):** the Freesound page shows Creative Commons 0, and the description now reads only "Reaktor 6 blocks preset." A third-party mirror (soundspool.com) shows an older description that asked users to give credit. CC0 doesn't require credit, but banan_ is credited above to respect that wish. The sound was rendered from a Native Instruments Reaktor 6 Blocks preset. Audio rendered from synth presets is normally the user's own output, so the risk is low.
- **town_captured (aUREa 475246):** made with Native Instruments Battery 4 (sampled drums) plus reverb. The uploader released the result as CC0. The risk is low, but note that it is built from commercial library samples.
- **win/lose/draw (trumpetplayer):** Reveille and Taps are traditional US military bugle calls in the public domain. The performances are released CC0 by the uploader.
- **Freesound licence changes:** an uploader can change a sound's licence later. The page snapshots in `art-sources/audio/placeholder/_sources/page_snapshots/` record the CC0 licence as of 2026-10-07.
- No Sonniss, no CC-BY, no CC-BY-NC, and no "Sampling+" sources are used.
